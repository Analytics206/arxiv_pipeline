# Dense Retrieval Baseline

> This one-paper smoke baseline has been superseded for model selection by the
> five-paper [Embedding Model Benchmark v2](embedding_benchmark_v2.md). Keep
> this smaller suite for fast end-to-end regression checks.

## Baseline

- Date: July 26, 2026
- Suite: `openforge-agent-retrieval-v1`
- Paper: OpenForgeRL (`2607.21557v1`)
- Analysis: `agent-paper-v5`, generated by `qwen3.5:4b`
- Embedding model: `mxbai-embed-large:latest`
- Vector size: 1,024
- Qdrant collection: `research_knowledge_v1`
- Hardware: RTX 2070 Mobile, 8 GB VRAM

| Metric | Result |
| --- | ---: |
| Cases | 6 |
| Recall at each case's limit (5) | 1.00 |
| Mean reciprocal rank | 1.00 |
| Provenance completeness | 1.00 |
| Mean query latency | 112.83 ms |

The runtime JSON report is saved under the ignored path
`data/retrieval_evals/openforge_mxbai_baseline.json`.

## Interpretation

This validates the complete dense retrieval path and catches basic regressions:
all reviewed queries retrieved an expected evidence ID at rank 1, and every
returned hit retained its page, quote, and evidence identifiers.

It is not yet evidence that dense-only retrieval is sufficient. The suite
covers one paper, only six questions, and terminology that is relatively close
to the source. Add more papers, paraphrased project questions, negative cases,
cross-paper comparisons, and near-duplicate methods before using the score to
choose a long-term embedding model or to skip hybrid retrieval.

## Compare another embedding model

1. Add the candidate model to the shared `ai-services`
   `OLLAMA_PULL_MODELS` list and recreate its Ollama service.
2. Choose a new collection name. Never mix embedding models in the same
   collection.
3. Index the same immutable analysis with the candidate.
4. Run the same suite against that collection.
5. Compare Recall@k, MRR, provenance completeness, mean/p95 latency, indexing
   time, model size, and observed GPU memory.

```powershell
docker compose run --rm --no-deps app `
  python -m src.pipeline.index_research `
  --paper-id 2607.21557v1 `
```
